## Setup your development environment

Get SamvadQL up and running on your local machine in just a few minutes.

<Steps>
  <Step title="Clone the repository">
    ```bash git clone https://github.com/your-org/samvadql.git cd samvadql ```
  </Step>
  <Step title="Configure environment">
    ```bash cp .env.example .env # Edit .env with your configuration ```
  </Step>
  <Step title="Start with Docker">```bash docker-compose up -d ```</Step>
  <Step title="Access the application">
    - Frontend: [http://localhost:3000](http://localhost:3000) - Backend API:
    [http://localhost:8000](http://localhost:8000) - API Documentation:
    [http://localhost:8000/docs](http://localhost:8000/docs)
  </Step>
</Steps>

## Your First Query

Now let's generate your first SQL query:

<Steps>
  <Step title="Enter natural language question">
    In the query editor, type: ``` Show me all users who signed up in the last
    30 days ```
  </Step>
  <Step title="Generate SQL">
    Click **"Generate SQL"** or press `Ctrl+Enter`
  </Step>
  <Step title="Review generated SQL">
    Watch as SamvadQL streams the SQL generation: ```sql SELECT * FROM users
    WHERE created_at >= CURRENT_DATE - INTERVAL '30 days' ORDER BY created_at
    DESC; ```
  </Step>
  <Step title="Execute the query">
    Click **"Execute Query"** to run it against your database
  </Step>
</Steps>

<Note>
  The AI provides explanations for each generated query to help you understand
  what it does.
</Note>

## Refine Your Query

SamvadQL supports conversational refinement:

<Steps>
  <Step title="Ask a follow-up question">
    ``` Only show users from the United States ```
  </Step>
  <Step title="AI modifies the query">
    ```sql SELECT * FROM users WHERE created_at >= CURRENT_DATE - INTERVAL '30
    days' AND country = 'United States' ORDER BY created_at DESC; ```
  </Step>
</Steps>

## Tips for Better Results

<CardGroup cols={2}>
  <Card title="Be Specific" icon="bullseye">
    Instead of "Show me sales", try "Show me total sales by product category for
    the last month"
  </Card>
  <Card title="Use Domain Language" icon="language">
    Instead of "Show me the table with people", try "Show me all customers"
  </Card>
  <Card title="Provide Context" icon="context">
    Instead of "Show me recent data", try "Show me orders from the last 7 days"
  </Card>
  <Card title="Iterate and Refine" icon="arrows-rotate">
    Start simple and add filters in follow-up questions
  </Card>
</CardGroup>
